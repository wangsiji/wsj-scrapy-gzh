大家好，我是秋秋。

3月如期结束，总体比我想象的丰富多彩～不仅读了很多书，还开始了一些新技能，一起看看我的总结吧！

我的3月关键词是调整，完成了这些：

一、学习


主要是读书、观影之类的，这些书籍电影，真的能让你的灵魂在路上。

书籍我月初计划看5本，实际只完成4本。电影看了4部，纪录片2个。


1
读书


// 1.《极简主义者的家》

 

读起来特别轻松有趣！

如果你每次收拾家都很累，那可能不是打扫的问题，而是你的东西太多。


极简主义的观点是：杂物不要浪费你的时间，物尽其用才是正好。

作者针对不同的空间极简，给了很多实用建议，比如：

1.趁着换季，你一年都没穿的衣服，可以考虑做成抹布或送人。

2.书籍可以电子化，喜欢藏书的人，设定一个数量，超过就扫描成电子版。

3.厨房上方收纳不要放重物（有安全隐患），把备用的卫生纸、垃圾袋放这里，更方便拿取。

总之，家里清爽了，人的心情也会变得愉悦。

这本书2-3个小时就能读完，干货不少，我打8分。


// 2.《也许你该找人聊聊》


书很厚，1500多页，但读起来就上瘾啊！！！！

我读之前以为是写：大家都经历了大的磨难那种......实际上这就是搞笑文学！？

作者像讲八卦一样，聊自己和男友分手的过程，每一个心理访谈，你都能看到奇奇怪怪的人，还有我们自己的影子。

我真的第一次看到，用这么幽默有趣的语言，写的心理学书籍！

读书笔记我放在这里：


看完书，真的不由自主地就被自愈了。

我是很容易忽视问题的人。看完书我知道，很多问题发生，原来以前就有表象。

而想要完成事情，也不必一蹴而就。就像走到浴室一样，想象只有5步，一步一步总会到达。


// 3.《一地鸡毛》


结婚后，真的因为一块豆腐就会吵架！

这是由好几个短篇小说组成的一部作品集，我只看了《一地鸡毛》这一篇。

男主角小林早上买了一块豆腐，结果忘记放冰箱了，坏了。

她老婆上班距离远、孩子要上幼儿园、保姆又耍滑头不好好照顾。

晚上老婆发现豆腐坏了.......一系列的家庭琐事就开始了。

看完觉得好真实，书里小林和老婆从前都是文艺青年，可生活，真的是由无数的琐事组成的啊！


// 4.《不持有的生活》


也是一本关于极简主义的书，不到200页很好读完。

“不持有”不意味着节俭、低标准的生活，而是不拥有“不必要”的东西。

不囤积、把物品发挥最大价值，甚至会花钱买你喜欢很久但有用的物品。

也就是东西不多，但每个都是自己喜欢的、有用的。

里面还有不同囤积类型的测试表，根据你的特点，教你怎么改变，很实用。


2
电影


// 1.《触不可及》
 

对于一个只有脖子能动的残疾人来说，什么样的照料是最可贵的？

这个讲了一个黑人小伙子去应聘，无意中成为有钱的残疾人“保姆”的故事。

在照料的过程中，小伙让残疾人菲利普学会了抽烟、有勇气约会自己的笔友，真正的体会到了快乐。

整个片子我大笑了不止十次，真的非常温馨！小伙最后还创办了自己的企业！难得可贵，故事是真人真事改编！


// 2.《花束般的恋爱》


两个相爱的人，是怎样越走越远的？

一开始，他们喜欢看一样的书、听一样的歌、有共同的兴趣爱好。

他们聊一整夜都不睡，搬到一起后，为彼此的梦想加油打气。


然后，男生做了一个需要经常加班的工作，意识到生活的不容易。

女生说：你不必过得那么辛苦啊！你依旧可以玩游戏、看书、简单的生活就很好！

男生说，那你把生活想得太简单了.......


我看完不知道是谁的问题，但我觉得这个问题，好像还挺普遍。

我和大老王吵架的时候，我是能理解他真的，做的一切还是为我好。

他除了吃没啥心眼，一想到这个，我就没有什么可生气的了。

// 3.《一百样东西》
 

标题大过内容，看完我只能打6分。

电影讲了两个朋友打赌，100天只回家拿一样东西，看谁坚持不下去的故事。

但除了前3天，后面讲极简的部分很少，男二中间还去谈恋爱了，男一我真的搞不懂除了最后去度假，和100样东西有啥关系.......


// 4.《恐怖游轮》


被朋友推荐的一部电影，还推荐了什么列车杀人案。

可是我真的看不懂😭

来来回回看了2遍，我才明白女主是为了救她儿子一遍遍上了游轮，循环前的她在救人，循环后的她在杀人。

里面有不少血腥的镜头，猝不及防......吓死我了😭 


3
纪录片


综艺、演讲、纪录片、听课都放这里吧～

   // 1.《无节制消费的元凶》


必看！

看完之后才知道，好多商家就是刺裸裸的“欺骗”！

照片打印机里面会带一个滚筒，打印到几百次就自动报废，实际上你把那个滚筒清0，就还能用！

苹果电池不耐用，因为他们就是要你不断买新产品。实际上换完电池，你的手机用更久，还没损失......

很多消费品，618、双十二，也不会真的便宜，用到再买才是最省钱的！


  // 2.《谷爱凌：我，18》


陆陆续续，趁着隔离期间晚上，看了好多关于谷爱凌的纪录片。

我真的好喜欢她妈妈，谷燕女士的教育方式！

对于大多数孩子来说，除了有钱，父母的情绪稳定更让人羡慕！

看完纪录片我才了解，极限运动真的很“苦”，会受伤、会脑震荡，雪季训练、每次她妈妈都要开1个多小时车程去滑雪场。

面临压力的时候，她妈妈从来都是：你不一定非要考斯坦福。你真的很棒。你是我的骄傲。

还有谷爱凌，她才18岁就说：我只需要做到我能做到的最好即可，做到自己最好，不意味着把别人比下去，而是能成为自己成为的、那个最好的人。

真的很喜欢她这种态度！


// 3.《正大综艺-动物来啦》


中央1台晚上放的一个综艺！

里面会讲很多小动物的爱好、习性，还有专家答疑。小动物有大熊猫、猫科动物、小猴子、野生动物系列等等。

央视出品！必属精品！这个老少皆宜，真的很好看。

三、生活


⛺️主要是开始骑行、露营了！真的很快乐！

 1.我爱骑行


现在妥妥是，都市快乐骑车女孩了👧

晚上兜着风，一个人骑遍大街，也算用车轱辘丈量北京了。

 2. 聚会好开心


我的好朋友终于脱单了！这是第一次带着她男朋友来家里玩。还有一个朋友没脱单。

第一次玩UNO，果然我输得最惨。大老王没想到还是游戏王者。

之后又一起玩了大富翁：


和朋友一起玩游戏，真的很快乐（总有人是游戏黑洞啊）！

 3. 带狗子出门了



有了自行车、有了小背包！我家小六一解锁户外模式了！

从买自行车到现在，每个周末都要外出骑行，狗狗也很开心。


骑行的时候我总是在后面，小六一就一脸担心得看着我。

当我努力骑到前面，它就特别兴奋！真是妈妈的好大儿～

 4.人生第一次露营


以前看别人住帐篷，就觉得好苦啊，有点落魄那感觉。

自己体验过后，这才是真人版野外求生！比各种经营游戏有趣多了！

什么都要亲力亲为，当我们坐在草地上，吹着春风，大老王问我，你知道什么是最富有的吗？


惟江上之清风，与山间之明月。



最后，给自己做总结，也是一个梳理思绪的过程。你完成or不完成计划，短暂来看，对你的人生不会有很大的影响。

我分享这些，是希望大家无聊的时候，也可以有个动力去尝试。

也许只是去看了一个电影都行。

希望我的总结能带给你些许的力量～
3月已经悄悄溜走了，4月在向我们招手！
